# 《老鼠进城》游戏设计提案

## 核心概念
玩家扮演一只聪明却身处险境的老鼠，需要潜入城市深处寻找家族线索。玩法强调“潜行 + 解谜 + 操作链”，通过多系统交互形成复杂而精美的操作流程。整体可切换为 **2D 俯视** 或 **2.5D 侧视** 的视角，同时保持高复杂度。

## 玩法结构（高复杂度循环）
1. **情报侦查**：利用嗅觉与视觉线索定位目标区域、避开猫与捕鼠陷阱。
2. **道具编排**：将收集到的道具组合成“操作链”（例如：硬币 → 触发售货机 → 掉落弹簧 → 弹射到管道）。
3. **环境操控**：利用通风管、电路开关、下水道阀门改变场景态势。
4. **潜行/追逐**：通过噪音管理、光影遮蔽在巡逻间穿梭。
5. **目标达成**：到达安全屋或关键剧情点，解锁新区域。

## 操作系统（复杂操作流程）
- **多工具栏切换**：玩家携带 3 个工具槽与 1 个即时槽，可快速轮换。
- **组合交互**：
  - 夹子 + 面包屑 = 诱饵陷阱（吸引猫离开）
  - 玻璃碎片 + 粘胶 = 攀爬点（进入高处管道）
  - 电池 + 铜线 = 临时电路（开启门禁）
- **多阶段操作**：
  1. 观察弱电门禁电流周期
  2. 手动卡住继电器（迷你 QTE）
  3. 快速潜入，关门后撤
- **噪音与气味模型**：高噪音会引发追击，气味残留会改变巡逻路线。

## 关卡设计（2D 但高复杂度）
### 1. 旧城区巷道
- **目标**：进入面包房仓库。
- **复杂链路**：  
  - 关闭垃圾车引擎 → 打开隐藏地沟 → 利用水流冲入仓库底部。
  - 或者：诱导人类打开后门 → 攀爬货箱 → 切断电源进入。

### 2. 地铁站台
- **核心机制**：震动与时间差。
- **复杂链路**：
  - 调整电路开关 → 暂停扶梯 → 在扶梯停顿间隙穿过 → 藏入电缆井。

### 3. 市政图书馆
- **核心机制**：光影与巡逻 AI。
- **复杂链路**：
  - 关灯 → 利用书架阴影移动 → 找到古旧地图解锁新剧情。

## 美术与表现（精美需求）
- **2D 高精度手绘 + 动态光影**
- **环境细节丰富**：垃圾堆、旧电线、雨水反光、城市霓虹。
- **角色动画**：攀爬、钻洞、奔跑、警觉、假死等精细动作。
- **UI**：老鼠洞主题的复古风格界面。

## AI 系统（高复杂度）
- **猫巡逻 AI**：具备记忆与路径学习，发现异常后会改变巡逻路线。
- **人类 AI**：动态行为，例如随机丢弃食物或开启门窗。
- **环境动态**：雨水、灯光闪烁、电力中断等造成节奏变化。

## 难度曲线
- **前期**：教学 + 单一机制。
- **中期**：多机制叠加 + 追逐压力。
- **后期**：多目标并行（例如需同时控制水阀与电路）。

## 可拓展内容
- **技能树**：嗅觉强化、攀爬速度、噪音控制。
- **支线任务**：救助同伴、寻找失落物品。
- **多结局**：依据玩家选择决定老鼠族群命运。

---

如果项目允许 3D，可将核心机制保持不变，仅扩展立体探索与镜头层次；若资源受限，则 2D 版本仍保证复杂操作链与高精细美术，以达到“足够复杂、足够精美”的要求。
